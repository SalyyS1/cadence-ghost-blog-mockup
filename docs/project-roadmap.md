# Project roadmap

## Complete

- Client-reference static mockup and responsive approval link.
- Ghost 6 dynamic theme with home, post, page and archive contexts.
- Members, Portal, gated content, search and native comments support.
- MySQL/Caddy Docker deployment, sample content, tests, packaging and operating docs.

## Production activation

- Select a Ghost host or Docker VPS.
- Point the production domain and start the Compose production profile.
- Create the owner account, activate Bateson and seed/import content.
- Connect SMTP/Mailgun; verify SPF, DKIM and DMARC.
- Optionally connect Stripe and configure paid tiers.
- Run a restore drill before launch.

## After launch

- Replace wireframe media with approved photography.
- Enter real advert destinations and social links.
- Review analytics, member conversion and newsletter deliverability monthly.
