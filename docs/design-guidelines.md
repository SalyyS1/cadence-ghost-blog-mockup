# Bateson design guidelines

## Direction

Swiss sports editorial: a white canvas, cobalt actions, black condensed-feeling headlines, pale grey media blocks and a disciplined three-column rhythm.

## Core rules

- Use Archivo or the Ghost-configured sans-serif fonts.
- Reserve cobalt for brand, focus and primary actions.
- Keep cards borderless; hierarchy comes from spacing, type weight and grey media surfaces.
- Use uppercase for navigation, metadata, tags and editorial headings.
- Desktop uses three columns, tablet two and mobile one.
- Missing images are intentional neutral placeholders, not broken-image icons.
- Motion is quiet: short fades, slight image scale and no decorative looping animation.

## Content imagery

Feature images should feel documentary rather than commercial. Supply descriptive alt text; use empty alt only where the same story title immediately labels a decorative hero image.
